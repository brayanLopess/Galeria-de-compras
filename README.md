✦ Galeria de Compras

Uma coleção pessoal de desejos, ideias e futuras aquisições — organizada em um só lugar.

A Galeria de Compras é um projeto web desenvolvido para reunir produtos que pretendo comprar, permitindo visualizar suas informações, consultar preços e organizar minha lista de desejos de maneira simples e visualmente agradável.

Com uma identidade visual inspirada no design editorial, o projeto combina tons neutros, tipografia elegante e uma interface minimalista para transformar uma lista de compras em uma experiência de navegação mais interessante.

◈ Visão geral

O objetivo do projeto é criar uma galeria pessoal na qual cada produto tenha seu próprio espaço, com imagem, nome, categoria e preço. A proposta é facilitar a consulta dos itens desejados e manter suas informações organizadas.

✦ Funcionalidades

Galeria de produtos: visualização dos produtos cadastrados em formato de cards.

Busca de produtos: campo de pesquisa para facilitar a localização de itens e consegue filtrar por categoria.

Cadastro de produtos: interface para adicionar novos produtos à coleção.

Informações detalhadas: apresentação do nome, da categoria, da imagem e do preço dos produtos.

Adição e remoção de produtos: Você consegue cadastrar produtos novos que você queira ao clicar no botão "Cadastrar novo produto" e remover eles caso já tenha comprado ou não queira mais aquele produto clicando em "Veja mais" e logo em seguida em "REMOVER PRODUTO". Cada produto fica salvo localmente no seu navegador, então caso você apague o seu cache do navegador, isso também fará com que os itens cadastrados sejam apagados.

Design responsivo: proposta de uma interface adaptável a diferentes tamanhos de tela.

◇ Identidade visual

O design foi pensado para transmitir simplicidade, personalidade e sofisticação, sem abrir mão da funcionalidade.

Paleta de cores - Preto, Bege, branco e tons neutros.
Tipografia - Combinação de fontes serifadas e sans-serif
Layout - Galeria organizada em cards
Estética - Editorial, minimalista e contemporânea
Experiência - Navegação direta e hierarquia visual clara

⌘ Tecnologias

As tecnologias utilizadas neste projeto podem ser consultadas no código-fonte do repositório.

    HTML5 — estruturação do conteúdo.

    CSS3 — estilização, layout e identidade visual.

    JavaScript — interatividade e comportamento da interface.

↗ Como executar o projeto
Para executar o projeto diretamente no navegador é só acessar o link que fica na parte "sobre".

Para executar o projeto localmente:

Clone este repositório:

git clone https://github.com/brayanLopess/Galeria-de-compras.git

Acesse a pasta do projeto:

cd Galeria-De-Compras

Abra o arquivo index.html no navegador ou utilize a extensão Live Server no Visual Studio Code.
